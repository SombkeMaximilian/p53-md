# VMD Scripts for Report Figures

VMD scripts in this directory generate the report figures. The `build` directory from the simulations must be present for them to work.

## Usage

Running the following command from the repository root loads the visualization config of the 1st replica:

```bash
vmd -e vmd/rep1.vmd
```
